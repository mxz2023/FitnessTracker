# 血压常识指南

## 什么是血压？

血压是血液在血管内流动时对血管壁产生的压力。

## 血压分类标准

| 分类 | 收缩压（mmHg） | 舒张压（mmHg） |
|------|---------------|---------------|
| 理想血压 | <120 | <80 |
| 正常血压 | 120-129 | 80-84 |
| 正常高值 | 130-139 | 85-89 |
| 高血压1级 | 140-159 | 90-99 |
| 高血压2级 | 160-179 | 100-109 |
| 高血压3级 | ≥180 | ≥110 |

## 测量注意事项

1. **测量前**：安静休息5-10分钟
2. **测量时**：坐姿正确，手臂与心脏平齐
3. **测量环境**：安静、舒适的温度
4. **测量频率**：早晚各测一次

## 高血压风险因素

- 年龄增长
- 家族遗传
- 肥胖
- 高盐饮食
- 缺乏运动
- 吸烟饮酒
- 长期压力

## 控制建议

- 低盐饮食（每日<6g）
- 戒烟限酒
- 规律运动
- 控制体重
- 减轻压力
- 遵医嘱服药

## 紧急情况识别

**需要立即就医的情况**：
- 血压>180/120 mmHg（高血压危象）
- 伴有剧烈头痛、视力模糊、胸痛
- 出现恶心、呕吐、意识障碍等症状

## 定期检查频率

| 人群类型 | 检查频率 | 注意事项 |
|---------|---------|---------|
| 正常人群 | 每年2次 | 建议家庭自测血压 |
| 高危人群 | 每季度1次 | 有家族史、肥胖者 |
| 高血压患者 | 每日监测 | 遵医嘱调整用药 |

## 注意事项

1. 血压测量应在标准化条件下进行
2. 不同时间段的血压值可能存在波动
3. 本指南仅供参考，不能替代专业医疗建议
4. 具体治疗方案需遵医嘱
