# 血脂常识指南

## 什么是血脂？

血脂是血液中脂类物质的总称，主要包括胆固醇和甘油三酯。

## 血脂四项指标

| 指标名称 | 理想水平 | 边缘升高 | 升高 |
|---------|---------|---------|-----|
| 总胆固醇（TC） | <5.2 mmol/L | 5.2-6.2 | ≥6.2 |
| 甘油三酯（TG） | <1.7 mmol/L | 1.7-2.3 | ≥2.3 |
| 低密度脂蛋白（LDL-C） | <3.4 mmol/L | 3.4-4.1 | ≥4.1 |
| 高密度脂蛋白（HDL-C） | ≥1.0 mmol/L | - | <1.0 |

## 血脂异常类型

1. **高胆固醇血症**：TC和/或LDL-C升高
2. **高甘油三酯血症**：TG升高
3. **混合型高脂血症**：多项指标异常
4. **低高密度脂蛋白血症**：HDL-C降低

## 心血管风险评估

根据血脂水平评估10年心血管病风险：

- **低危**：无危险因素，血脂轻度异常
- **中危**：1-2个危险因素
- **高危**：≥3个危险因素或已有心血管病
- **极高危**：急性冠脉综合征、糖尿病等

## 饮食调理

**推荐食物**：
- 富含膳食纤维：燕麦、豆类、蔬菜
- 富含不饱和脂肪酸：橄榄油、坚果、鱼类
- 富含植物固醇：大豆、玉米、小麦

**限制食物**：
- 饱和脂肪酸：动物脂肪、黄油
- 反式脂肪酸：油炸食品、糕点
- 高胆固醇：动物内脏、蛋黄

## 生活方式干预

- 有氧运动：每周150分钟中等强度运动
- 体重管理：BMI控制在18.5-24.9
- 戒烟限酒
- 压力管理
- 规律作息

## 紧急情况识别

**需要立即就医的情况**：
- 出现胸痛、胸闷、呼吸困难等心血管症状
- 伴有头晕、乏力、意识模糊等严重症状
- 血脂极度异常伴有其他危险因素

## 定期检查频率

| 人群类型 | 检查频率 | 注意事项 |
|---------|---------|---------|
| 正常人群 | 每2年1次 | 建议定期体检 |
| 高危人群 | 每年1次 | 有家族史、肥胖者 |
| 血脂异常患者 | 每半年1次 | 遵医嘱调整治疗 |

## 注意事项

1. 血脂检查前应空腹12小时
2. 不同年龄段的理想血脂水平可能不同
3. 本指南仅供参考，不能替代专业医疗建议
4. 具体治疗方案需遵医嘱
